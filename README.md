# Mini Militia Arena

A lightweight, single-file 2D jetpack arena shooter inspired by Mini Militia, built with HTML5 Canvas and the Web Audio API.

## Features
- **Jetpack Combat:** Fly across multi-tier steel bunkers and crates with rechargeable jetpack fuel.
- **3 Weapons + Grenades:** Assault Rifle (`1`), Shotgun (`2`), Rocket RPG (`3`), and bouncing Frag Grenades (`G` / `E`).
- **Two Game Modes:** Deathmatch (first to 10 kills) and Survival (1 life).
- **AI Militia Bots & Pickups:** 4 jetpack-equipped enemy bots plus respawning Medkit, Ammo, and Grenade pickups.
- **Desktop & Touch Controls:** Keyboard + mouse aiming, plus toggleable on-screen touch controls (`Pad`).

## Play Locally
Open `index.html` directly in any modern browser—no build step or dependencies required.
